# Windows Steam 스킬 도감 캡처

스킬 목록을 순서대로 열어 레벨별 설명 이미지를 저장하는 로컬 도구입니다. 게임을 직접 실행하고 로그인한 뒤, 도감 화면의 위치를 한 번 지정합니다. 타자/투수와 스킬 티어가 달라지면 별도 프로필로 수집합니다.

**현재 상태:** 캡처·중단·재개 로직은 모의 화면으로 검증했습니다. 실제 Windows Steam 게임에서는 아직 검증하지 않았습니다. 우선 **1개 테스트** 결과를 확인하세요. 게임이 화면 캡처를 지원하지 않아 검은 화면으로 나오거나 도감 구조가 아래 전제와 다르면 사용을 중단하고 설정 화면부터 확인해야 합니다.

## 실행

1. Windows에 [Python 3.12 64-bit](https://www.python.org/downloads/windows/)를 설치합니다. 설치 옵션의 Python Launcher(`py`)를 포함하세요.
2. 이 폴더 전체 또는 배포 ZIP을 압축 해제하고 **시작.bat**를 실행합니다. 첫 실행 때 필요한 라이브러리를 도구 폴더의 `.venv`에 설치하므로 인터넷 연결이 필요합니다.
3. Steam에서 게임을 실행하고 **창 모드**로 기본 모니터 안에 배치합니다. 창 전체가 화면 안에 보여야 합니다.
4. **스킬 도감 → 같은 티어·타자/투수 필터 → 목록 맨 위**로 이동합니다. 다른 설명창은 닫습니다.
5. 캡처 도구에서 게임창을 선택하고 프로필 이름을 입력합니다. 예: `골드-타자`, `골드-투수`.

기본 저장 위치: `%USERPROFILE%\Documents\RivalsSkillCapture`.

## 처음 한 번 위치 지정

**① 위치 설정**을 누르면 멈춰 있는 게임 화면 이미지가 나타납니다. 안내에 따라 영역을 드래그하거나 점을 클릭한 뒤 Enter를 누릅니다. 위치를 선택하는 동안 실제 게임에는 클릭을 보내지 않습니다.

| 지정할 곳 | 선택 방법 |
|---|---|
| 필터 영역 | 현재 타자/투수·티어를 식별하는 고정 부분. 시간·재화·목록 제외 |
| 목록 영역 | 스킬 이름 열을 위부터 아래까지. 아이콘·스크롤바 제외 |
| 스킬 행 | 완전히 보이는 **모든 행**을 위에서 아래 순서로 클릭. 최소 2개 |
| 빈 공간 | 마우스를 옮겨 둘 자리. 버튼·스킬·설명창 제외 |
| 설명창 전체 | 스킬명·선택된 레벨·효과 설명이 모두 보이게 선택 |
| 스킬명 | 글자만 선택. 레벨·아이콘·움직이는 배경 제외 |
| 레벨 버튼 줄 | 모든 레벨 버튼과 선택 표시 포함. 설명·스킬명 제외 |
| 닫기 / 각 레벨 | 해당 버튼의 중앙 클릭 |

목록 위치를 지정하면 도구가 첫 스킬을 한 번 열어 설명창 위치를 지정하게 합니다. 이후 지정한 레벨을 차례로 클릭해 선택 표시를 기준 이미지로 저장하고 설명창을 닫습니다.

**현재 게임에 실제로 있는 레벨만 입력하세요.** 설명창을 열었을 때 기본 선택되는 레벨도 포함해야 합니다. 기본 입력은 `S4,S3,S2,S1,S,A,B,C,D`이며, 없는 버튼은 위치 설정 전에 삭제하세요. 화면이 가로 목록·격자·드롭다운 형태이거나 설명창을 별도로 열고 닫는 구조가 아니면 이 버전을 그대로 적용할 수 없습니다.

## 수집

```text
① 위치 설정 → ② 1개 테스트 → 이미지 확인 → ③ 전체 수집 / 이어서
                      ↓
             스킬명 · 레벨 · 설명이 모두 맞는지 확인
```

- 첫 테스트는 첫 스킬의 지정 레벨만 저장합니다. 결과 폴더에서 선택 표시와 설명을 확인하세요.
- 전체 수집은 목록의 행을 열고, 각 레벨을 캡처한 뒤 한 칸씩 스크롤합니다. 겹치는 항목은 스킬명 이미지로 중복 확인합니다.
- 시작 시 게임창을 활성화합니다. 수집 중에는 게임창을 이동·확대하거나 다른 작업을 하지 마세요. 마우스를 움직이는 것도 피하세요.
- **Esc**, 마우스 왼쪽 위 이동, 다른 창으로 전환 중 하나로 중단할 수 있습니다. 버튼 선택 상태·필터·창 크기가 달라져도 중단합니다.
- 스크롤 이동이 더 이상 감지되지 않으면 `bottom_detected`로 멈춥니다. 마지막 스킬까지 저장됐는지 확인하세요. 스크롤 불응과 실제 목록 끝을 완전히 구별하지 못하므로 전체 완료를 단정하지 않습니다.
- 다른 티어/투수로 바꿀 때는 새 프로필을 만드세요. 도구가 필터를 자동으로 바꾸지는 않습니다.

## 이어서 수집

설명창을 닫고 **같은 필터의 목록 맨 위**로 돌아갑니다. `프로필 불러오기`에서 기존 `profile.json`을 선택하고 전체 수집을 누릅니다. 저장된 레벨은 건너뛰며 누락된 파일만 다시 수집합니다. 이름 영역이 움직이거나 픽셀이 달라지면 같은 스킬을 추가 저장할 수 있으므로 나중에 이름과 설명을 함께 검수합니다.

위치·크기·게임 UI 배율을 변경했으면 **새 프로필 이름으로 위치를 다시 지정**하세요. 이미 수집한 프로필의 좌표를 덮어쓰지 않습니다.

## 결과 전달

`공유용 ZIP 만들기`로 해당 프로필을 묶습니다. ZIP에는 선택한 게임 영역 캡처와 수집 기록만 들어갑니다. 도감 영역을 넘겨 계정 정보 등이 포함되지 않았는지 결과 이미지를 확인하세요.

```text
profile-골드-타자/
  profile.json         위치·레벨 설정
  state.json           항목별 완료 레벨과 중단 이유
  calibration/         필터·레벨 선택 기준 이미지
  skill_0001/
    name.png           이름 영역
    S0.png             게임의 S 레벨
    S1.png
    S2.png
    ...
```

게임의 `S`는 파일에서 `S0`, 옛 `SS`는 `S1`, `SS+`는 `S2`로 대응합니다. `state.json`에는 입력한 원문 레벨도 보존합니다. **S3/S4 효과를 예전 SS+에서 추산하지 않습니다.** 전체 설명과 숫자는 이미지를 확인한 뒤 별도로 구조화합니다. OCR·점수 변경·서버 업로드는 이 도구에서 수행하지 않습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 검은 캡처 | 창 모드로 전환하고 1개 테스트. 계속 검으면 해당 환경에서 캡처 불가 |
| 레벨 상태 확인 실패 | 실제로 있는 레벨인지, 선택 테두리가 영역에 포함되는지, 클릭 대기 시간이 충분한지 확인 |
| 이름 영역 변경 | 이름만 선택했는지 확인. 레벨·설명·애니메이션 제외 |
| 스크롤 겹침 확인 실패 | 목록 이름 열을 충분히 넓게 지정하고 Windows 휠 한 칸의 이동량을 줄인 뒤 맨 위에서 재시작 |
| 다른 창/위치 오류 | 게임창을 원래 크기·위치로 복원하고 맨 위에서 재시작 |
| 게임창 미표시 | 게임 실행 후 창 목록 새로고침. 게임이 최소화돼 있다면 먼저 복원 |

화면에 보이는 도감만 마우스로 조작하며, 게임 메모리·파일·통신에는 접근하지 않습니다. 창 제목·프로세스 실행 파일명은 선택한 창을 확인하는 데 사용합니다. 게임의 자동 입력 제한 여부는 여기서 확인되지 않았습니다.

개발 검증: `python -m unittest discover -s tools/skill-capture -p 'test_*.py' -v` (저장소 루트에서 실행, requirements 설치 필요).
