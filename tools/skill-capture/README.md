# Windows Steam 스킬 도감 캡처

현재 프로그램은 선수 기본 능력치·미페 수집도 지원합니다. 통합 GUI 사용법은 [GUI_README.md](GUI_README.md)를 참고하세요.

**S 설명 저장 → S1 이상 선택·저장 → `>>`로 다음 스킬 → 첫 스킬로 돌아오면 다음 탭** 순서로 수집합니다. 일반·모먼트·WBC·블랙·HOF 탭을 선택해 연속 수집할 수 있습니다.

사용자가 설명한 **모바일 화면 흐름**을 바탕으로 만들었습니다. Windows Steam에서는 처음 한 번 실제 버튼 위치를 지정해야 합니다. 모의 게임과 Windows 프로그램 실행은 자동 검사하지만 **실제 Steam 게임 캡처는 아직 검증하지 않았습니다.** Steam 화면 구조가 다르면 무리하게 좌표를 맞추지 말고 1개 테스트에서 확인하세요.

## 실행

1. [Python 3.12 64-bit](https://www.python.org/downloads/windows/)를 설치합니다. Python Launcher(`py`)를 포함하세요.
2. ZIP을 압축 해제하고 **시작.bat**를 실행합니다. 첫 실행 때 필요한 라이브러리를 `.venv`에 설치하므로 인터넷 연결이 필요합니다.
3. Steam 게임을 창 모드로 실행하고 창 전체를 기본 모니터 안에 배치합니다.
4. 게임에서 **메인 → 구단관리 → 선수도감 → 스킬**로 들어갑니다. 이 진입 단계는 직접 진행합니다.
5. 설명창과 레벨 선택 목록을 닫은 상태에서 캡처 도구의 게임창·프로필 이름·수집할 탭을 선택합니다.
6. **① 위치 설정 → ② 1개 테스트 → 결과 확인 → ③ 전체 / 이어서** 순서로 실행합니다.

기본 저장 위치: `%USERPROFILE%\Documents\RivalsSkillCapture`.

## 캡처 범위

2026-11-06 사용자가 게임에서 확인해 제공한 최대 레벨을 적용했습니다. 스킬을 처음 열었을 때 보이는 기본 S를 먼저 저장합니다.

| 스킬 종류 | 캡처 레벨 |
|---|---|
| 일반 | S, S1, S2, S3, S4 |
| 모먼트 | S |
| WBC | S, S1, S2 |
| 블랙 시그니처 | S, S1, S2 |
| HOF | S, S1 |

타입별 상한을 넘는 레벨은 선택하지 않습니다. 파일 이름은 게임의 S를 앱 표기인 `S0.png`로 저장합니다. S3·S4 수치를 옛 SS+에서 추산하지 않습니다.

## 처음 한 번 위치 지정

멈춰 있는 게임 화면 이미지 위에서 안내에 따라 영역을 드래그하거나 버튼 위치를 클릭하고 Enter를 누릅니다. 위치를 선택하는 동안에는 게임에 클릭을 보내지 않습니다. 선택을 끝내면 지정한 버튼을 눌러 다음 설정 화면을 엽니다.

| 지정할 곳 | 선택 방법 |
|---|---|
| 탭 줄 | 일반/모먼트/WBC/블랙/HOF와 선택 표시 포함. 시간·재화·목록 제외 |
| 빈 공간 | 마우스를 둘 자리. 버튼·드롭다운·설명창 제외 |
| 각 탭 | 선택한 탭 버튼 중앙 |
| 각 탭의 첫 스킬 | 첫 번째 스킬을 여는 카드/버튼 중앙 |
| 설명창 전체 | 스킬명·선택 레벨·효과 설명을 모두 포함 |
| 스킬명 | 이름 글자만. 레벨·아이콘·움직이는 배경 제외 |
| 레벨 표시 | **S에서 S1 등으로 변하는 표시**만. 변하지 않는 '현재레벨' 글자만 잡으면 안 됨 |
| 레벨 선택 버튼 | 현재레벨 오른쪽의 상위 레벨 목록을 여는 버튼 |
| 다음 / 닫기 | 하단 `>>`와 설명창을 닫는 버튼 |
| 레벨 목록 영역 | 펼쳐진 선택 목록 전체. 선택 표시 포함, 스킬명 제외 |
| 각 상위 레벨 | S1~해당 종류 상한의 항목 중앙 |
| S 복귀 항목 (선택) | 목록에 기본 S로 돌아가는 항목이 보이면 선택. 없으면 아무 곳도 누르지 않고 Enter |

공통 설명창 위치는 한 번 지정하고, 탭과 레벨 목록 위치는 선택한 각 종류마다 지정합니다. 모먼트는 S만 캡처하므로 레벨 목록 설정을 생략합니다. 설정이 끝나면 스킬 탭 화면으로 돌아갑니다.

`>>` 이동 때 레벨이 S로 초기화되면 S 복귀 항목이 없어도 됩니다. 상위 레벨이 유지된다면 지정한 S 복귀 항목을 사용합니다. 둘 다 불가능하면 S를 잘못 저장하지 않고 중단합니다.

## 자동 수집 흐름

```text
첫 번째 선택 탭 → 첫 스킬 열기 → S부터 상한까지 저장
                                      ↓
                                  >> 다음 스킬
                                      ↓
                    첫 스킬인가? ─ 아니오 → 레벨별 저장 반복
                          ↓ 예
                    설명창 닫기 → 다음 선택 탭
```

- 첫 스킬의 이름 이미지를 기록해 한 바퀴 돌았는지 판단합니다. 돌아온 첫 스킬을 다시 저장하지 않습니다.
- `>>`를 눌러도 이름이 바뀌지 않으면 멈춥니다. 클릭 실패와 스킬이 한 개뿐인 탭을 구별할 수 없어 자동 완료로 처리하지 않습니다.
- 첫 스킬이 아닌 이전 스킬로 돌아와도 중단합니다.
- 레벨 목록·선택 표시·스킬명·탭 표시가 기준과 다르면 중단합니다.
- **Esc**, 마우스 왼쪽 위 이동, 다른 창으로 전환으로 멈출 수 있습니다.
- 수집 중에는 게임창을 이동·확대하거나 마우스·키보드를 사용하지 마세요.
- 첫 스킬만 수집하는 **1개 테스트**는 `>>`나 다음 탭으로 이동하지 않습니다. 먼저 레벨과 설명이 올바르게 저장되는지 확인하세요.

## 이어서 수집

설명창과 드롭다운을 닫고 같은 **스킬 탭 화면**에서 시작합니다. 일부 탭만 설정했다면 그중 하나를 선택해 두세요. `프로필 불러오기`로 기존 `profile.json`을 선택한 뒤 전체 수집을 누릅니다.

완료한 탭은 건너뛰고, 중단된 탭은 첫 스킬부터 다시 순회하면서 저장된 레벨을 건너뜁니다. 파일이 빠져 있으면 다시 수집합니다. 다음 업데이트에서 스킬/효과가 추가된 경우에는 새 날짜의 프로필로 수집하세요.

창 크기·UI 배율·좌표·수집할 탭이 달라졌으면 새 프로필 이름으로 위치를 다시 지정합니다. 초기 목록 스크롤 방식의 프로필은 새로 설정해야 합니다.

## 결과

`결과 ZIP 만들기`로 선택한 모든 탭의 결과를 묶습니다.

```text
profile-스킬도감-2026-11-06/
  profile.json
  state.json                 탭별 진행·순환 확인·레벨별 저장 기록
  calibration/               탭·이름·선택 레벨·드롭다운 기준 이미지
  normal/skill_0001/           일반
    name.png
    S0.png
    S1.png ... S4.png
  moment/skill_0001/S0.png
  wbc/skill_0001/...
  black/skill_0001/...
  hof/skill_0001/...
```

화면에 보이는 도감을 마우스로 조작하며 게임 메모리·파일·통신에는 접근하지 않습니다. 창 제목·실행 파일명으로 선택한 창을 확인합니다. 게임의 자동 입력 제한 여부는 여기서 확인되지 않았습니다.

캡처 이미지의 이름·티어·레벨·조건·효과를 검수한 뒤 점수 계산에 사용해야 합니다. 이 도구는 OCR·점수 변경·서버 업로드를 수행하지 않습니다. 공유 전 이미지에 불필요한 계정 정보가 포함되지 않았는지 확인하세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 검은 화면 | 창 모드에서 1개 테스트. 계속 검으면 해당 환경에서 캡처 불가 |
| 레벨 표시가 구분되지 않음 | 실제 S/S1 선택 표시를 잡았는지, 클릭 후 대기 시간이 충분한지 확인 |
| 다음 스킬에서 기본 S로 돌아오지 않음 | S 복귀 항목이 있으면 새 프로필에서 지정 |
| 다음 스킬 이름이 바뀌지 않음 | `>>` 위치, 대기 시간, 해당 탭의 스킬 개수 확인 |
| 첫 스킬이 기준과 다름 | 목록 정렬·필터 확인. 게임 업데이트로 변경됐다면 새 프로필 |
| 이름 영역 변경 | 이름 글자만 선택했는지 확인. 등급·레벨·효과 제외 |
| 다른 창/위치 오류 | 게임창을 원래 위치·크기로 복원하고 스킬 탭 화면에서 재시작 |

개발 검증: `python -m unittest discover -s tools/skill-capture -p 'test_*.py' -v`.
패키지 재생성: `python scripts/package_skill_capture.py`.
