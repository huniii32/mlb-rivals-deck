# Rivals 도감 수집기 — Windows GUI

스킬 설명, 선수도감 기본 능력치, 선수 미페를 선택해서 수집하는 Windows 10/11 프로그램입니다.

## 실행

- 실행 파일 배포본: ZIP을 풀고 `RivalsGuideCollector.exe` 실행.
- Python 배포본: Python 3.12 설치 후 `시작.bat` 실행. 기존 스킬 캡처 프로필도 불러올 수 있습니다.
- 실제 Steam 화면에서는 처음 한 번 위치 지정과 **1개 테스트**가 필요합니다. 모의 게임·Windows GUI·OCR 검증과 실제 게임 도감 검증은 구분됩니다. 실제 Steam 게임에서의 전체 수집은 아직 확인하지 않았습니다.

## 선택 가능한 기능

1. 스킬 설명 수집 — 일반 S~S4, 모먼트 S, WBC/블랙 S~S2, HOF S~S1.
2. 선수 기본 능력치 수집 — 선수 정보, 능력치 원본과 숫자.
3. 선수 미페 수집 — 선수 정보와 미페 영역 PNG.
4. 선수 정보 + 능력치 + 미페 — 한 번에 수집.

스킬 수집 절차는 `README.md`를 참고하세요.

## 선수 수집

1. Steam 게임을 창 모드로 실행합니다.
2. 선수도감에서 수집할 구단·등급 필터와 정렬을 정하고 **첫 선수 상세 화면**을 엽니다.
3. 프로그램에서 게임창과 실행할 기능을 선택합니다.
4. 프로필 이름과 현재 필터 설명을 입력합니다. 예: `NYY 모먼트 / 기본 정렬`. 필터나 창 크기·레이아웃이 바뀌면 새 프로필을 사용합니다.
5. 능력치 수집 시 화면에 있는 항목 이름을 쉼표로 모두 입력합니다. 예: `파워,정확,선구`. 입력한 각 항목의 **숫자만 있는 영역**을 지정하므로 다른 숫자를 임의로 매칭하지 않습니다. 미페 전용은 비워도 됩니다.
6. `① 위치 설정`에서 정지된 화면 위에 영역과 다음 선수 화살표를 지정합니다. 설정 중 게임의 버튼은 누르지 않습니다.
7. `② 1개 테스트` → `선수 결과 검토`에서 원본과 수치를 확인합니다.
8. 다시 같은 첫 선수 상세 화면에서 `③ 전체 / 이어서`를 실행합니다.

식별에는 **선수명 + 카드 정보 영역**을 함께 사용합니다. 구단·등급·연도·테마 또는 카드 번호 등 같은 선수의 다른 카드를 구분하는 정보를 포함하세요. 미페 애니메이션·재화·시간은 제외해야 합니다. 화면에서 구분할 수 없는 두 카드는 자동으로 구분할 수 없으므로 필터를 나누어 별도 프로필로 수집하세요.

다음 화살표로 이동한 뒤 식별 정보가 안정되었는지 확인합니다. 첫 카드로 돌아오면 **현재 선택한 필터의 한 바퀴** 완료로 표시합니다. 같은 카드에서 움직이지 않거나 첫 카드 외의 이전 카드가 반복되면 중단합니다. 최대 카드 수 도달은 완료로 처리하지 않습니다. 구단·등급 필터 자체는 자동으로 바꾸지 않습니다.

## 문자 인식과 검토

- Windows 내장 OCR을 사용하며 캡처 이미지를 외부 서버로 보내지 않습니다. 한국어 인식 언어가 있으면 우선 사용합니다. 없다면 Windows 사용자 언어로 인식하므로 한글은 수동 검토해야 합니다. Windows 설정의 언어 옵션에서 한국어 OCR을 설치할 수 있습니다.
- 원본 PNG는 항상 먼저 저장합니다. OCR 실행이 실패해도 캡처 파일은 유지합니다.
- `수집 후 Windows 로컬 문자 인식`을 켜면 정상 수집 완료 또는 1개 테스트 후 인식합니다. 중단된 결과는 `선수 문자 인식 / 재시도`로 처리할 수 있습니다.
- 숫자 영역이 0~999 정수 하나로 명확히 읽혔을 때만 값을 제안합니다. `1O5`, 여러 숫자, 빈 문자열은 빈값으로 남깁니다. 미인식을 0점으로 바꾸지 않습니다.
- `선수 결과 검토`에서 원본 상세 화면과 값들을 비교하고 수정한 뒤 카드별로 저장합니다. 이름·구단·카드 종류와 모든 수집 능력치를 확인해야 검토 완료로 표시할 수 있습니다.
- OCR 값은 자동으로 검증 완료 처리하지 않습니다. 직접 수정한 값은 OCR 재시도가 덮어쓰지 않습니다.

## 결과

기본 폴더: `문서\RivalsSkillCapture\profile-프로필이름`.

```text
profile.json              수집 기능·필터·좌표
state.json                진행 상태와 카드별 검토 기록
players.json              원본 경로·OCR 원문·수정값·검토 상태
players.csv               엑셀에서 열 수 있는 UTF-8 표
cards/card_00001/
  detail.png              상세 화면 원본
  identity.png            구단·등급·연도·테마 식별 원본
  name.png                선수 이름
  stats.png               기본 능력치 표 (선택 시)
  stat_01.png ...          각 기본 능력치 숫자 (선택 시)
  portrait.png            미페 영역 (선택 시)
```

CSV/JSON은 **선수도감 기본 능력치**로 표시합니다. 미페는 화면에 보이는 이미지를 자른 것이며 게임 내부 원본 파일이나 투명 배경 파일을 추출하지 않습니다. `결과 ZIP 만들기`로 묶을 수 있습니다. 웹사이트의 덱·선수 DB·이미지는 자동으로 덮어쓰지 않습니다.

중지: 프로그램 `중지`, Esc, 마우스를 왼쪽 위로 이동, 다른 창으로 전환. 이어서 수집은 같은 필터의 첫 선수 상세 화면에서 시작하며 기존 카드는 건너뛰고 누락 파일은 다시 저장합니다.
