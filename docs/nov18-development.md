# 11월 18일 업데이트 개발 시험

브랜치: `feat/nov18-skills-deck-update`. 2026-11-19 사용자 요청으로 최종 검증 후 운영 배포한다.

## 구현 범위

- 공식 v4.08.00의 WBC 키스톤·사령관·하모니(타자/투수) S~S2 조건별 30개 점수.
- 비교 화면은 조건 수동 선택, 실제 덱은 WBC 카드 여부·현재 배치·등록 라인업의 카드 국가로 자동 판정.
- 선수 편집에 WBC 카드 뒷면 국가 입력 추가. 기존 덱에 임의 국가를 부여하지 않는다.
- 하모니는 이름이 등록된 WBC 카드만 세고 자신을 포함한다. 미입력 국가가 점수 구간을 바꿀 수 있으면 미확인으로 표시하고 임시 합계에서 제외한다. 이미 4명 이상이 확인된 경우 추가 미입력 선수는 최대 효과에 영향을 주지 않는다.
- 덱에서 시뮬레이터로 선수를 가져올 때 실제 판정 조건을 전달한다. 정보가 없으면 먼저 국가 확인을 요청한다. 기존처럼 S1/S2는 시뮬레이터의 S 레벨로 환산한다.
- 11/18 공식 확률표 15종을 다시 수집·검증. WBC 관련 4종의 12포지션이 변경됐으며 나머지 11종은 11/05와 동일하다. 스킬 변경권 추첨 레벨과 포훈 보너스의 S3 달성은 별개다.
- 파워 피쳐의 괄호 뒤 O/X를 보존해 조건 선택지를 구분한다. 점수는 기존 O 47.5 / X 23.5 유지.
- 승리조 적극 전술을 이름이 등록된 선수 1명 이상부터 +2 적용. 추격조 적극 2명 / 승리조 분업 3명 유지.

## 데이터 미확보로 보류한 부분

- 포훈 21~26 전체 증가표, 해당 포지션·선호 구단 효과 판정은 아직 완성하지 않았다. 미확인 구간을 입력하면 기존 20레벨까지 확인된 증가량을 유지하고 추가 증가분이 누락된 임시 계산임을 안내한다. 기존 20레벨 증가량을 갑자기 0으로 되돌리지 않는다. 사용자 지정 표가 있으면 기존 사용자 표 우선 규칙을 유지한다.
- 블랙 S3 효과는 게임 도감의 실제 수치 확보 후 추가한다. 기존 S2 수치를 추정 확대하지 않는다.
- 리더 영향력은 게임에 표시된 합계를 입력하는 기존 방식을 유지한다. 전체 레벨별 조건표와 비교 능력치 확보 전 자동 판정을 추가하지 않는다.
- 선호 구단·선호 구단 효과 저장 및 21레벨 이상 적용 여부 자동화는 위 증가표와 함께 구현한다.

## 시험 및 운영 분리

Cloudflare 브랜치 빌드는 `VITE_DEVELOPMENT_SANDBOX=1`로 Supabase 클라이언트를 생성하지 않는다. 미리보기의 덱·랭킹은 브라우저 로컬 데이터로만 시험하고, 실제 공개 랭킹·이벤트 RPC를 호출하지 않는다. 기존 운영자 인증 보호는 유지한다. 로컬 시험은 다음과 같이 시작한다.

```sh
VITE_DEVELOPMENT_SANDBOX=1 npm run dev -- --host 127.0.0.1 --port 5177
node scripts/verify-nov18-browser.cjs
```

`npm test`에 새 점수, 조건 경계, 저장/가져오기, 랭킹 페이로드, 최종 능력치 보존, 포훈 미확인 구간, 전술 최소 인원, WBC 확률 및 시뮬레이터 점수 통합 검사를 포함했다. 종료된 이벤트의 서버 규칙 SQL·당첨 결과는 변경하지 않는다.
