# 라인업 표 보기 도안

## 최신 제안: 한 장 요약표

사용자가 제공한 참고 이미지에 맞춘 `lineup-sheet.html`을 우선 적용안으로 사용한다.
화면 이미지는 `sheet-preview.png`, `sheet-mobile.png`다.

- 타자 9명과 선발·불펜 12명을 **타선 / 마운드** 두 표에 연속 표시한다.
- 상단 오른쪽 총점과 선수별 점수는 노란색, 스킬 합산 점수는 하늘색으로 강조한다.
- 선수 행에는 포지션·역할, 강화, 이름, 카드 종류, 최종 능력치, 능력 점수, 스킬 점수, 최종점을 표시한다.
- 스킬 이름과 육성 세부 입력은 선수명 클릭 후 상세창에서 보여준다.
- 불펜 역할은 승리1~3·추격1~2·롱릴·마무리처럼 짧게 표기하고, 전술 가산 +4/+2를 따로 표시한다.
- 하단에는 팀덱코·스덱코 선택을 작은 좌/우 칸으로 요약한다. 도안의 선택값은 예시다.
- 모바일에서도 가로 스크롤 없이 전체 열을 맞춰 표시한다. 긴 선수명은 줄임표와 상세창으로 확인한다.
- 능력치·스킬·총점은 예시 값이며, 실제 구현 시 기존 엔진의 결과를 그대로 표시한다.

## 이전 제안: 넓은 비교표

`lineup-table.html`은 외부 의존성이 없는 인터랙티브 도안이다. 선수와 수치는 예시이며
실제 앱의 계산 엔진·저장·랭킹에 연결하지 않는다.

## 적용 방향

- 라인업 제목 오른쪽에 **일러스트 / 표 보기** 전환을 둔다. 두 보기에서 같은 덱 데이터를 사용하고 보기 선택만 기기에 기억한다.
- 표 보기에서는 팀 버프와 덱스코어 패널을 접어서 표의 가로 공간을 확보한다.
- **전체 / 타자 / 선발 / 불펜** 필터로 같은 선수 목록을 좁혀 본다. 필터·검색은 덱의 실제 선수 순서나 타순을 바꾸지 않는다.
- 타자: 포지션, 선수·카드, 타순, 파워, 정확, 선구, 스킬, 최종점.
- 투수: 역할, 선수·카드, 변화, 구위, 전술 가산, 스킬, 최종점.
- 불펜 위에는 3/2/1/1 배치와 승리조 분업 +4·추격조 적극 +2를 요약한다. 기존 불펜 배치·전술 편집 UI를 연결한다.
- 능력치는 전술이 포함된 최종값이다. 전술 열은 이미 적용된 값의 설명이며 재가산하지 않는다.
- 선수 이름을 누르면 기존 상세 편집창을 연다. 표에는 비교할 값만 남기고 육성 세부 입력은 편집창에 둔다. 네 번째 스킬이 있으면 같은 칸에 줄바꿈해 표시한다.
- 모바일은 포지션·선수명 열을 고정하고 나머지 열을 가로 스크롤한다.

도안에서 필터, 검색, 보기 전환, 선수 이름 클릭, 예시 능력치 변경을 체험할 수 있다.
일러스트 보기는 전환 체험을 위한 축약 표시이며 실제 구현 시 기존 야구장 UI를 사용한다.
