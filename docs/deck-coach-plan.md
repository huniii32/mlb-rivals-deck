# 육성 우선순위 + 내 덱 코치

같은 분석 결과를 추천 카드와 질문형 코치에서 사용한다. 계산 엔진이 수치를 산출하고 OpenAI API는 확인된 계산과 게임 규칙을 바탕으로 설명한다. 현재 단계는 연결 설계이며 실제 OpenAI API 호출·과금은 추가하지 않았다.

## 데이터 흐름

1. 사용자가 ‘내 덱 분석’을 누르면 덱과 적용 조건을 서버로 전달한다.
2. 서버가 기존 엔진으로 현재 점수를 계산하고 강화·훈련·가능한 스킬 대안별 변화량을 산출한다. 가능한 강화 단계와 카드별 제한을 먼저 검증한다.
3. 우선순위 후보, 점수 변화, 조건과 근거 규칙을 OpenAI API에 전달한다. 모델이 임의의 점수나 게임 효과를 만들어 계산하지 않도록 한다.
4. 화면에 추천 3개와 근거·조건을 표시하고, 같은 분석 결과로 후속 질문에 답한다. 데이터가 없는 효과와 잠재력은 별도로 ‘계산 미반영’으로 구분한다.

화면 예시: ‘육성 우선순위’ 카드 → 추천 선수와 변경 사항 → 예상 덱 점수 변화 → ‘왜 이 선수가 먼저인가요?’ 질문. 실제 승률이나 게임 성능이 그대로 상승한다고 단정하지 않는다.

## 구현 시 필요한 설정

- Cloudflare Pages Function/Worker 또는 별도 서버에서 OpenAI Responses API를 호출한다. OpenAI 키는 서버 secret으로만 설정하며 `VITE_` 변수에 넣지 않는다.
- 사용할 API 모델 ID는 실제 계정에서 제공되는 모델로 정한다. 대화에서 사용한 모델 별칭이 API ID와 같다고 가정하지 않는다.
- 사용자별 호출 횟수·출력 길이 제한, 덱 해시와 점수표 버전별 분석 캐시, 월 예산 상한을 설정한다. API 비용과 사용량은 서버에서 기록한다.
- 덱 저장/편집은 기존 화면에서 사용자가 수행한다. 첫 버전의 코치는 조언과 비교 결과를 제공한다.
- API 키, 사용 가능한 모델, 월 예산을 정한 뒤 연결하고, 계산 결과와 모델 설명의 일치·근거 없는 추천·모르는 효과 처리부터 검증한다.
