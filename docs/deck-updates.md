# 덱 저장·랭킹·자동 계산 변경

## 사용 방법

- 이름 없는 덱은 작성 중인 임시 덱이다. 이름을 정하고 **덱 저장**을 눌러야 이 기기에 보관된다.
- 온라인 랭킹이 연결되어 있으면 첫 저장 시 비밀번호(8~128자)를 정한다. 이후 수정은 같은 랭킹 행에 즉시 반영한다. 전송 중 추가 수정은 직전 요청이 끝나면 최신 내용으로 반영한다.
- 다른 기기에서 **덱랭킹 → 내 덱의 가져오기 → 비밀번호**로 관리 권한을 연결한다. 기기마다 다른 수정 토큰을 발급하므로 휴대폰과 노트북의 권한이 함께 유지된다.
- 공개 랭킹의 선수 구성·점수는 계속 공개된다. 비밀번호는 원래 랭킹 행을 수정하는 관리 권한을 보호한다. 공유 링크는 복사본만 전달한다.
- 여러 기기에서 서로 다른 내용을 수정하면 마지막으로 서버에 도착한 덱이 반영된다. 다른 기기의 열려 있는 편집 내용을 자동으로 병합하지 않는다.

## 강화·훈련·덱스코어

최종 능력치를 직접 입력했던 선수도 강화·초월·훈련·카드·덱코·연도 조건 변경에 따른
자동 합계 차이를 기존 최종값에 반영한다. 직접 입력값과 자동 합계의 보정 차이는 보존한다.
최종값을 지우거나 **최종값을 자동 합계로 전환**을 누르면 전체 자동 합계를 사용한다.
훈련재분배의 무작위 결과는 게임에서 확인한 새 훈련 수치를 입력해야 한다.

점수 규칙에 연결된 덱스코어 선택 86개에 대해 조건을 충족하는 선수를 구성하여
정확한 가산값, 수동 최종값 반영, 선택 해제 시 복원을 검증한다.
규칙에서 사용하는 `라이브/시즌` 카드가 선택 목록에 없어 적용할 수 없던
스페셜 380/560 좌, 팀 280/375/460 좌 조건을 선택 가능하게 수정했다.
라이브/시즌의 강화·초월 조견표는 기존 자료에 없으므로 해당 레벨의 자동 가산은
제공하지 않으며 화면에 표 누락을 표시한다. 확인되지 않은 육성 수치는 추가하지 않았다.

팀 330/345는 원본 규칙에 평가 대상 능력치 가산이 없어 선택만 유지하며 이를 화면에 표시한다.
스페셜 615/645/680은 기준 연도를 입력하면 0~9년 이내 선수에게 가산한다.

## 운영 DB 적용

프런트엔드 배포 전에 Supabase SQL Editor에서 관리자 권한으로 순서대로 실행한다.
기존 `supabase_mig_owner_codes.sql`이 적용된 DB를 전제로 한다.
레거시 `supabase_mig_ranking_upsert.sql`도 사용할 경우 비밀번호 마이그레이션보다 먼저
적용한다. 비밀번호 전환 뒤 구 등록 RPC의 실행 권한을 다시 열지 않는다.

1. `scripts/supabase_mig_bullpen.sql`
2. `scripts/supabase_mig_deck_passwords.sql`
3. 이번 랭킹 초기화: `scripts/supabase_reset_rankings_20261105.sql`

세 번째 스크립트는 기존 랭킹과 소유 권한을 비공개 `ranking_reset_archive` 스키마에
백업하고 개수를 확인한 뒤 공개 랭킹을 비운다. 같은 스크립트를 다시 실행해도
초기화 후 새로 등록된 덱은 삭제하지 않는다. 기기의 로컬 덱은 삭제하지 않는다.
초기화 후 기존 연동은 다음 갱신에서 해제되며 덱 저장으로 비밀번호를 정해 재등록한다.
비밀번호는 bcrypt 해시, 기기 수정 토큰은 SHA-256 해시로만 보관하고 공개 테이블과 분리한다.

이 작업 환경에는 운영 DB 관리자 자격 증명이 없어 운영 SQL 실행·초기화는 수행하지 않았다.
비밀번호 마이그레이션이 없는 서버에서는 오류를 표시하고 이 기기의 덱은 보존한다.
운영 데이터를 쓰거나 삭제하지 않는 로컬 PostgreSQL(PGlite)에서 SQL을 검증했다.

## 검증

- `npm test`: 기존 계산·엑셀 가져오기·불펜·신규 스킬 27항목·덱코 86선택·연도 3조건·수동 최종값 갱신.
- `npm run test:db`: 실제 PostgreSQL 엔진에서 비밀번호 RPC, 복수 기기 권한, 잘못된 비밀번호·토큰 거절, 공개 접근 제한, 초기화 백업·재실행.
- `npm run build`: TypeScript 검사와 배포 빌드.

## 라인업 보기

기본 화면은 일러스트이며 상단의 표 보기 버튼으로 한 장 요약표로 전환한다.
두 보기는 같은 선수 데이터와 계산 엔진 결과를 사용한다. 표에서 선수명을 누르면
기존 상세 편집창이 열린다. 표 아래의 접힌 설정에서 불펜 배치·전술·팀 버프·덱코를
수정할 수 있다. 새로고침하면 일러스트로 시작하며 저장된 덱 데이터는 유지된다.
