# 과거 스킬 레벨과 현재 표기

공식 변경 근거: [v2.07.00 업데이트](https://community.withhive.com/MLB9IRIVALS/ko/board/9/8164)의 초월 시스템 / 스킬 레벨 표기 변경표.

| 과거 표기 | 현재 공식 표기 | 앱에서 쓰는 표기 |
|---|---|---|
| D / C / B / A | D / C / B / A | 동일 |
| S | S | S0 |
| SS | S1 | S1 |
| SS+ | S2 | S2 |
| 당시 대응 없음 | S3 | S3 |
| 당시 대응 없음 | S4 | S4 |

- **SS+를 S3·S4로 변환하지 않습니다.** v2.07.00에서 초월 9레벨 효과와 함께 S3가 추가됐습니다.
- S4는 [v4.07.00 공지](https://community.withhive.com/MLB9IRIVALS/ko/board/9/17979)에서 골드 티어의 포지션 훈련·초월 9레벨·블랙 카드 +1 효과를 포함한 상한으로 확인됩니다.
- 공식 자료는 기본 단계를 S로 표기합니다. S0는 앱의 기본 S 레벨 구분용 표기입니다.
- 이 대응표는 **레벨 이름의 대응**입니다. 효과 수치가 이후 패치에서도 그대로 유지됐다는 뜻이 아닙니다.
- 옛 자료에 S·SS·SS+만 있으면 해당 자료는 S0·S1·S2까지만 근거가 됩니다. S3·S4 수치는 별도 자료 없이 채우거나 등차로 추산하지 않습니다.
- 스킬 티어(골드·블랙 등)와 스킬 레벨(S·S1 등)은 별개입니다. 티어마다 도달 가능한 레벨을 같은 것으로 가정하지 않습니다.
- OCR은 SS와 S, SS+와 S2를 잘못 읽을 수 있으므로 원본 이미지와 함께 확인합니다.

수집 원문의 표기와 숫자는 그대로 보존하고, 구조화 자료의 `row_level_labels`에 정규화한 이름을 별도로 기록합니다. 등급 열이 없는 효과 설명 배열은 문맥 검토 전까지 자동 분해하지 않습니다.
