# 스킬 변경권 시뮬레이터 (최고급·고급·일반)

진입: 상단 **시뮬레이터 → 스킬 시뮬레이션**. 화면 순서: 변경권·카드 설정 → 통계 → 스킬 결과·실행. 상세 설명·조건·기록은 기본 접힘입니다.

확률 기준: 2026-11-05 개별 확률표. 확인일: 2026-11-06 UTC.

`src/data/skillProbabilities.json`에 공식 HTML의 SHA-256, 주소, 확인일과 각 포지션·스킬·레벨의 표시 확률을 보존합니다. `python3 scripts/import_skill_probabilities.py`로 재생성하며, `--refresh`를 붙이면 다시 다운로드합니다. 원문은 `data/skill-probabilities/`에 캐시됩니다.

Excel HTML은 CP949입니다. `%`가 붙지 않은 일부 확률 셀은 소수 비율로 저장되므로 100을 곱해 퍼센트로 변환합니다. 각 시트·포지션의 확률 합계를 검사하고, 100%에서 0.0001%p 이상 벗어나면 생성에 실패합니다. 표의 반올림 오차를 실제 확률 변경으로 해석하지 않습니다.

## 최고급 변경권 슬롯 규칙

| 카드 | 슬롯 | 첫 슬롯 | 나머지 슬롯 |
|---|---:|---|---|
| 일반/임팩트/프라임/시그니처 | 3 | 골드 100% | 브론즈 35 / 실버 40 / 골드 25% |
| 모먼트 | 3 | 카드별 전용 모먼트 6 / 골드 94% | 일반 카드와 동일 |
| 슈프림 모먼트 | 3 | 모먼트 30 / 골드 70% | 일반 카드와 동일 |
| HOF | 3 | HOF 10 / 골드 90% | 브론즈 31.5 / 실버 36 / 골드 22.5 / HOF 10% |
| 시그니처 블랙 | 4 | 블랙이 아닌 경우 골드 확정 | 블랙 외 브론즈 20 / 실버 30 / 골드 50% |
| WBC 시그니처/프라임 | 3 | 골드 90 / WBC 10% | 동일 |
| WBC 블랙 시그니처 | 4 | 블랙 외 골드 90 / WBC 10% | 동일 |

블랙 계열은 먼저 네 슬롯 중 블랙 위치를 각각 25%로 선정하며, 결과에 블랙은 정확히 한 개만 등장합니다. 모먼트는 첫 슬롯에서만 등장합니다. 일반 모먼트는 사용자가 해당 카드의 전용 스킬을 한 종류 선택합니다. 슈프림 모먼트는 포지션에 맞는 모먼트 전체 목록을 사용합니다.

## 일반·고급 변경권 슬롯 규칙

| 카드 | 일반 변경권 (슬롯별) | 고급 변경권 (슬롯별) |
|---|---|---|
| 일반 카드 / 모먼트 / 슈프림 모먼트 | 아이언 35 / 브론즈 30 / 실버 20 / 골드 15% | 일반과 동일 |
| HOF | HOF 0.1%, 일반 티어 99.9% | HOF 1.5%, 일반 티어 98.5% |
| 시그니처 블랙 | 일반 카드와 동일 | 블랙 5%, 일반 티어 95% |
| WBC 시그니처·프라임 | 골드 100%, 모두 S | 골드 99.5 / WBC 0.5%, 모두 S |
| WBC 블랙 | 골드 100%, 모두 S | 골드 94.5 / WBC 0.5 / 블랙 5%, 모두 S |

일반 티어 비중은 아이언:브론즈:실버:골드 = 35:30:20:15입니다. 일반·고급 변경권에는 첫 슬롯 골드 보장이 없습니다. 모먼트 전용 스킬은 최고급에서만 등장합니다. 블랙은 4슬롯을 유지하며 일반 변경권에서는 블랙 스킬이 나오지 않습니다 ([블랙 추가 공지](https://community.withhive.com/MLB9IRIVALS/ko/board/9/13358)).

고급에서 블랙이 한 번 나오면 뒤 슬롯은 일반 고급 확률로 전환합니다. WBC 블랙의 경우 뒤 슬롯은 골드 99.5 / WBC 0.5%로 전환합니다. 블랙을 제거한 95% 가중치를 단순 정규화하지 않습니다. 슬롯을 앞에서부터 처리하는 순서는 모델 가정이며, 블랙을 2개 요구하는 목표는 차단합니다.

## 일괄 실행 중단과 사용량

1회·10회·100회·입력 횟수 실행은 해당 카드의 전용 스킬이 하나라도 나오면 즉시 멈춥니다. 당첨 결과를 기록한 뒤 중지하므로 100회 요청 중 97회째 당첨되면 97장만 집계하며 해당 조합을 화면에 유지합니다. 전용 스킬이 나오지 않으면 요청 횟수까지 실행합니다.

- 모먼트·슈프림 모먼트: 최고급의 모먼트 등장 시 중지.
- HOF: 모든 변경권에서 HOF 등장 시 중지.
- WBC: 고급·최고급에서 WBC 등장 시 중지.
- 블랙: 고급에서 블랙 등장 시 중지. 최고급의 확정 블랙에는 중지하지 않음.
- WBC 블랙: 고급은 WBC 또는 블랙, 최고급은 WBC 등장 시 중지.
- `목표 조합까지`: 위 자동 중지 대신 선택한 목표 스킬·레벨 조합 완성 시 중지.

카드·변경권·포지션·목표를 바꾸면 기록을 초기화합니다. 버튼을 다시 누르면 이전 사용량부터 누적하며 이번 실행 사용량과 누적 사용량을 구분해 표시합니다.

## 스킬 점수 목표

진행 방식은 자유 변경 / 목표 스킬 조합 / 스킬 점수 목표 중 선택합니다. 점수 목표는 **변경되는 스킬 합계**가 입력값 이상이면 중단합니다. 3슬롯 카드는 잠금 없이 3개 합계, 첫 줄 잠금 시 잠긴 스킬을 제외한 2·3번째 2개 합계를 사용합니다. 잠금 불가인 블랙 계열은 4개 합계입니다. `목표까지 돌리기`는 전용 스킬이 먼저 등장해도 점수 목표를 달성할 때까지 계속합니다. 1·10·100회 버튼은 기존 전용 스킬 중단 규칙을 유지합니다.

- `src/lib/simulatorScore.ts`는 덱관리의 `skillScore`와 현재 `SkillTables` 수정값을 그대로 호출합니다. 추첨 레벨 S를 기존 점수표의 S0로 매핑하며 성장 보너스 S1~S4는 제외합니다.
- 이름 매칭은 공백·대소문자 정규화, 공식 WORLD BASEBALL CLASSIC → WBC, 파워 피처 → 파워 피쳐만 허용합니다. 유사 이름을 추측하지 않습니다.
- 선발·중계·마무리 역할과 도전정신의 카드 조건을 먼저 맞춥니다. 그 밖의 조건이 여러 개면 최저 점수 조건을 기본값으로 쓰며, **점수 기준 · 조건 설정**에서 O/X·능력치 구간 등을 직접 선택할 수 있습니다. 게임 상황을 자동 추정한 점수가 아닙니다.
- 중계 전용 신규 스킬의 SP/CP 효과 미적용은 기존 `calcPlayer`와 동일하게 0점 처리합니다.
- 변경되는 슬롯에 S 미만 또는 점수 미등록 스킬을 포함하는 결과는 합계 `평가 불가`로 기록하고 점수 목표·최고점에서 제외합니다. 임의의 레벨 배율이나 0점을 만들지 않습니다.
- 목표 판정은 표시와 동일하게 합계 소수 둘째 자리 반올림값을 사용합니다. 잠긴 스킬을 제외한 평가 가능한 후보들의 상위 점수 합계보다 높은 목표는 실행을 막습니다(슬롯 제약을 풀어 계산한 보수적 상한).
- 현재 조합이 이미 점수 목표를 만족하면 추가 변경권을 소비하지 않습니다.

검증: `scripts/verify-simulator-score.ts`의 기존 스킬 점수 일치, 조건 O/X, 사용자 수정값, 포지션 역할, 미등록/하위 레벨 제외, 잠금 제외 2개 합계·상한, 미등록/하위 레벨 잠금 제외, 목표 달성 회차 검사.

## 첫 슬롯 잠금

- 일반 카드·WBC는 현재 결과의 첫 슬롯을 잠글 수 있습니다.
- 모먼트·슈프림 모먼트는 첫 슬롯에서 모먼트 전용 스킬을 획득해야 잠글 수 있습니다 ([모먼트 공지](https://community.withhive.com/MLB9IRIVALS/ko/board/9/9032), [슈프림 모먼트 공지](https://community.withhive.com/MLB9IRIVALS/ko/board/9/16627)).
- HOF는 잠금 불가입니다. 사용자 요청에 따라 블랙·WBC 블랙도 현재 잠금 기능을 비활성화합니다. 일반·WBC의 잠금 가능 여부는 사용자 확인 규칙입니다.

잠금은 첫 스킬의 이름·티어·레벨을 그대로 유지하고 2·3번째 슬롯만 추첨합니다. 첫 슬롯 골드 보장을 두 번째 슬롯에 옮기지 않습니다. 잠근 이름은 다른 슬롯의 후보에서 제외합니다. 잠금·해제 시 누적 사용량과 티어 집계는 유지합니다. 서로 다른 합계 기준이 섞이지 않도록 최고점·목표·최근 결과 기록은 초기화하고 관측 비율은 현재 잠금 기준의 실행 횟수로 계산합니다.

변경권이나 S 보호 설정을 바꾸어도 잠근 스킬은 유지합니다. 카드·포지션·카드 전용 모먼트 스킬 선택을 바꾸면 잠금을 해제합니다. 기록 초기화는 현재 결과·잠금을 유지합니다.

전용 스킬 자동 중단과 티어 집계는 **새로 변경한 슬롯만** 확인합니다. 이미 잠긴 모먼트/WBC를 새 당첨으로 취급하지 않습니다. 목표 조합은 잠긴 스킬도 포함해 검사하며, 잠긴 스킬만으로 이미 목표를 만족하면 추가 변경권을 소비하지 않습니다. 잠긴 A 스킬에 S 이상을 요구하거나 남은 두 슬롯에 서로 다른 세 스킬을 요구하는 목표는 차단합니다.

## 샘플링과 가정

1. 카드별 공식 규칙으로 슬롯의 티어를 선택합니다.
2. 해당 포지션·티어의 스킬을 개별 확률의 상대 가중치로 선택합니다.
3. S 보호를 선택하면 이미 전 슬롯이 S인 선수로 보고 S를 유지합니다. 모먼트 계열도 전 슬롯 S 상태를 기준으로 합니다. WBC는 변경권 결과 자체가 S 확정입니다.
4. 그 외에는 선택한 스킬의 원문 D/C/B/A/S 확률을 사용합니다. 기본 분포는 40/30/20/7/3%입니다.
5. S1~S4는 성장 보너스이므로 변경권 추첨 결과에 넣지 않습니다.

2026-11-06 사용자가 게임에서 확인한 규칙에 따라, 한 번의 변경 결과에서는 동일 스킬이 중복 등장하지 않도록 항상 적용합니다. 중복 허용 옵션은 제거했습니다. 레벨이 달라도 이름이 같으면 제외하며, 다음 변경에서는 다시 등장할 수 있습니다.

중복 처리의 내부 순서는 공식 표에 명시돼 있지 않습니다. 시뮬레이터는 티어 선택 후 앞 슬롯에 나온 이름을 그 티어의 후보 목록에서 제외하고 남은 가중치를 정규화합니다. 중복 불가 규칙은 사용자 확인값이고, 티어를 먼저 선택하는 순서는 모델 가정입니다. 슬롯 간 결합 분포가 게임 서버와 동일하다고 확정하지 않습니다.

천장/확정 누적 보상, D~A 보호권의 세부 확률 재분배는 구현하지 않습니다. S 보호 해제는 매 시도의 원문 분포를 뽑는 모드입니다. 모먼트의 잠금되지 않은 슬롯의 이전 D~A 레벨을 누적 보존하는 과정을 임의로 만들지 않도록 모먼트 계열은 S 상태로 한정했습니다.

## 결과 해석과 검증

목표는 한 번의 결과에 선택한 스킬이 모두 등장하는 조합이며, 슬롯 순서는 무관합니다. 목표 최소 레벨도 함께 검사합니다. 블랙 2개·일반 카드 브론즈 3개 등 함께 나올 수 없는 목표는 실행 전에 차단합니다.

관측 비율은 `목표 달성 횟수 / 실행 횟수`입니다. 목표가 처음 나오면 멈춘 샘플의 비율로 모집단 확률이나 평균 소모량을 추정하지 않습니다. 누적 사용량·목표 달성 횟수·첫 달성 위치·최근 결과를 보여주며, 실제 계정·변경권·덱 데이터에는 연결하지 않습니다.
