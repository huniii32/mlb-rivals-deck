# 슈프림 모먼트 조합 시뮬레이터

진입: 상단 **시뮬레이터 → 슈프림 모먼트 조합**. 확인일: 2026-11-06 UTC.

## 기본 구성과 확정권

매회 **모먼트 재료 1장 + 나머지 재료 2장 + 등급 보호권 1장** 사용을 전제로 합니다. 사용자가 게임에서 확인한 보호권 사용 확률인 **슈프림 15% / 모먼트 85%**를 적용합니다. 이 수치는 모먼트 재료 3장의 합산 확률과 같습니다. 보호권 사용 후 확률은 공식 공지에서 직접 확인한 값과 구분하여 화면에 안내합니다.

- 확정권 미사용: 전체 30개 구단.
- 구단 확정권: 선택한 구단.
- 지구 확정권: 선택한 지구의 5개 구단.
- 리그 확정권: 선택한 리그의 15개 구단.

확정권은 선수 풀을 제한하며 등급 확률을 유지합니다. 설정을 바꾸면 실험 기록을 초기화합니다. 조합 중에는 설정을 변경할 수 없습니다.

## 선수와 테마

[현재 공식 조합 대상](https://futuremlb-fn.qpyou.cn/futuremlb/push/IndividualRates/261105/RV1105LD.files/sheet159.htm)의 **슈프림 744개 / 모먼트 2,686개 카드 항목**을 사용합니다. 같은 선수라도 구단·테마가 다르면 별도 카드입니다.

- 모먼트: 같은 확률표의 `sheet145.htm`에서 구단·테마·선수명을 읽어 현재 조합 대상과 이름별 개수까지 대조합니다.
- 슈프림: 공식 `MSL072203`, `MSL092203`, `MSL110503_01` 명단의 11개 시트를 합치고 현재 조합 대상과 대조합니다. 과거 명단에만 있는 6개 항목은 제외합니다. 이름별 개수가 일부만 일치하면 추측하지 않고 수집을 실패 처리합니다.
- 이름과 테마는 공식 명단 표기를 사용합니다. 슈프림 4개 테마는 공식 한국어 제목, 모먼트 20개 테마는 공식 영문 엠블럼명을 표시합니다.
- 후보·획득 기록에 선수명·구단·테마를 표시하며, 접힌 선수 명단에서 검색 및 50개씩 더 보기를 제공합니다.

등급을 먼저 뽑고 선택 범위 안의 해당 등급 **카드 항목을 균등 추첨**합니다. 개별 카드의 결합 확률은 공식 조합 표에서 확인되지 않아 이 부분은 모델 가정입니다.

재수집: `python3 scripts/import_combination_roster.py --refresh`. 원본 캐시는 `data/combination-roster/`에, 검증된 결과와 원본 URL·SHA-256은 `src/data/combinationPlayers.json`에 저장합니다.

## 후보와 선택

5번 독립 추첨하여 후보를 공개합니다. **섞고 선택하기**를 누르면 Fisher–Yates 셔플 후 뒤집힌 카드 1장을 선택합니다. 숨긴 상태의 화면·클래스·접근성 이름에는 선수·구단·테마·등급을 노출하지 않습니다. 선택 후 후보와 획득 카드를 공개합니다. 같은 카드가 후보에 여러 번 나올 수 있습니다.

일괄 실행은 5장 중 균등 무작위 1장을 고릅니다.

- 후보에 슈프림이 하나 이상 포함될 확률: `1 − (1 − 0.15)^5 = 55.62946875%`
- 뒤집힌 후보 중 고른 1장이 슈프림일 확률: `15%`

10회·100회·최대 횟수 실행은 **실제로 획득한 카드**가 설정한 목표와 일치할 때 중단합니다. 기본 목표는 슈프림 아무나이며, 선수 명단에서 희망 카드들을 선택하면 그중 하나를 얻을 때까지 계속합니다. 후보에만 나온 것은 당첨으로 세지 않습니다. 동일한 선수라도 구단·테마가 다른 카드는 희망 카드와 구분합니다. 실제 실행 횟수를 N이라 하면 재료 `3N장`, 등급 보호권 `N장`, 선택한 확정권 `N장`을 집계합니다. 결과 카드를 재사용하거나 월간 무료 기회를 반영하지 않습니다.

## 저장 · 희망 카드 · 분석

- `rivals.simulator.combination.v1`에 확정권 범위, 희망 카드 ID, 횟수, 결과·최근 기록, 후보 공개/셔플/선택 상태를 저장합니다. 새로고침 후에도 뒤집힌 카드의 순서·선택 단계가 유지됩니다. 서버·덱랭킹에는 전송하지 않습니다.
- 희망 카드는 선수 명단의 검색과 등급 필터를 통해 여러 개 고를 수 있습니다. 원하는 선수의 여러 테마를 추가하거나 원하는 테마의 여러 선수를 추가할 수 있습니다. 기본 목표는 슈프림 아무나입니다.
- 확정권 범위를 바꾸면 범위를 벗어난 희망 카드는 제외합니다. 빈 희망 목록은 일괄 실행을 막고 카드 선택을 안내합니다. 목표 변경 시 기록을 초기화하며 후보 선택 중에는 변경할 수 없습니다.
- 조합 기록에서 독립 실험 분석 창을 열 수 있습니다. 각 실험의 목표는 현재 희망 목록 또는 슈프림 아무나이며, 단위는 조합 회수입니다. 기존 재료·보호권·확정권 사용량에는 더하지 않습니다. 성공한 실험의 조건부 평균·중앙값과 상한 미달성 수를 구분합니다.
