# 슈프림 모먼트 조합 시뮬레이터

진입: 상단 **시뮬레이터 → 슈프림 모먼트 조합**. 확인일: 2026-11-06 UTC.

## 공식 규칙

- [현재 공식 확률표, 6. 조합](https://hive-fn.qpyou.cn/markup/img/tf/mlbrv/mlb9irivals_ko.html)
- [카드 조합 추가 공지, 2. 카드 조합 시스템](https://community.withhive.com/MLB9IRIVALS/ko/board/9/16627)

재료 카드는 정확히 3장입니다. 모먼트 조합 카드는 모먼트와 같은 재료 가치입니다. 각 재료의 확률을 합산하고 슈프림 모먼트 → 모먼트 → 시즌/라이브 S → A → B → C 순서로 100%까지만 배정합니다. 아래는 재료 **1장당** 공식 표시값입니다.

| 재료 | 슈프림 | 모먼트 | S | A | B | C |
|---|---:|---:|---:|---:|---:|---:|
| 모먼트 | 5 | 29 | 66 | 0 | 0 | 0 |
| S | 0 | 1 | 34 | 66 | 0 | 0 |
| A | 0 | 0 | 1 | 34 | 65 | 0 |
| B | 0 | 0 | 0 | 10 | 34 | 56 |
| C | 0 | 0 | 0 | 0 | 10 | 90 |

S 재료의 모먼트 확률은 최신 확률표의 1%를 사용합니다. 최초 추가 공지의 0.5%를 사용하지 않습니다. S 행은 공식 표에서 합계 101%로 표시되지만 임의 정규화하지 않고 공식 상위 등급 우선 합산·초과분 버림 규칙을 적용합니다.

예시:

- 모먼트 3장 → 슈프림 15%, 모먼트 85%.
- 모먼트 + S + C → 슈프림 5%, 모먼트 30%, S 65%.
- S 3장 → 모먼트 3%, S 97%.
- C 3장 → B 30%, C 70%.

## 후보와 선택

5번 독립 추첨하여 후보를 만듭니다. 모먼트 이상 후보가 있으면 후보 등급을 먼저 공개하고, 사용자가 **섞고 선택하기**를 누르면 Fisher–Yates 셔플 후 뒤집힌 카드 1장을 선택합니다. 실제로 뒤집어 섞은 뒤 선택하는 방식은 사용자가 확인했습니다. 숨긴 상태의 클래스·접근성 이름에도 후보 등급을 노출하지 않습니다.

모먼트 이상 후보가 없으면 5장 중 무작위 1장을 즉시 획득합니다. 일괄 실행 역시 5장 중 균등 무작위 1장을 고릅니다. 가장 높은 후보를 자동 획득하지 않습니다.

모먼트 3장 조합에서:

- 후보에 슈프림이 하나 이상 포함될 확률: `1 − (1 − 0.15)^5 = 55.62946875%`
- 뒤집힌 후보 중 고른 1장이 슈프림일 확률: `15%`

두 확률과 통계를 분리해 표시합니다. 10회·100회·최대 횟수 실행은 **획득한 카드**가 슈프림일 때 중단하며, 당첨 회차까지의 실제 조합 횟수와 `횟수 × 3` 재료 사용량만 집계합니다. 후보에만 슈프림이 나온 것은 당첨으로 세지 않습니다.

## 범위와 검증

등급만 시뮬레이션합니다. 개별 선수 추첨, 구단·지구·리그 확정권, 모먼트 등급 보호권은 구현하지 않습니다. 매회 같은 구성의 새 재료 3장을 투입하며 결과 카드를 자동으로 재사용하지 않습니다. 재료를 바꾸면 실험 기록을 초기화합니다.

- `scripts/verify-moment-combination.ts`: 재료 125조합의 총합·우선순위, 예시 확률, 후보 5개, 셔플 보존, 실제 획득 15%와 후보 포함 55.63%의 고정 시드 빈도 검증.
- 브라우저: 후보 공개 → 셔플 → 선택, 등급 숨김, 실제 97회 당첨 시 재료 291장 집계, 모먼트 없는 조합의 즉시 획득, 모바일·태블릿·데스크톱 검사.
