# 일반 명예의 전당 영입 시뮬레이터

2026-11-06 확인. 재료 등록 완료 후 획득하는 HOF 선수 1명을 추첨한다.

## 공식 출처

- [확률 안내](https://hive-fn.qpyou.cn/markup/img/tf/mlbrv/mlb9irivals_ko.html)
- [2026-11-05 일반 영입 HOF팩 선수별 확률](https://futuremlb-fn.qpyou.cn/futuremlb/push/IndividualRates/261105/RV1105LD.files/sheet188.htm): NORMAL RECRUIT HOF PACK, 28명.
- [v3.02.00 HOF 영입 안내](https://community.withhive.com/MLB9IRIVALS/ko/board/9/10742): 일반 영입은 월 1회, 계정 한정 영입은 별도. 특별 영입과 명단을 섞지 않는다.

개요는 1/n의 동일 확률을 안내한다. 개별 표는 앞 27명 각각 3.571428%, 마지막 Roberto Clemente 3.571444%로 합계 100%다. 이 시뮬레이터는 표시된 개별 확률을 정수 가중치(퍼센트의 백만분의 일)로 그대로 사용한다. 원본 URL, 날짜와 SHA-256을 데이터에 기록한다. 중복 획득은 허용하며 검색·희망 선수 선택은 추첨 명단이나 확률을 바꾸지 않는다.

## 사용 범위

- 1·10·100회, 최대 100,000회까지 희망 선수 추첨. 선택한 선수 중 하나가 등장한 회차에서 즉시 중단한다. 97회에 획득하면 97회만 집계한다.
- 희망 선수 미선택 시 요청한 횟수를 모두 수행한다. 여러 명 선택 시 확률은 해당 선수들의 확률 합계다.
- 전체 획득 수, 선수별 획득 수, 최초 획득 회차, 최근 12개 결과를 저장한다. 목표를 바꿔도 기록을 유지하며 현재 선택한 선수의 전체 기록으로 목표 통계를 다시 계산한다.
- 브라우저 로컬 저장. 다른 기기 및 덱랭킹과 동기화하지 않는다. 출처 표가 변경되거나 저장 데이터가 유효하지 않으면 이전 기록을 불러오지 않는다.
- 반복은 독립 추첨의 확률 실험이다. 월간 제한, 계정 한정 할인, 재료비, 재료 조건 초기화, 달력 경과는 시뮬레이션하지 않는다. 실제 게임에서 그 횟수만큼 영입할 수 있다는 의미가 아니다.

## 갱신과 검증

`python scripts/import_hof_recruit.py --refresh`로 공식 개요의 최신 개별 확률표와 NORMAL RECRUIT HOF PACK 탭을 찾아 수집한다. 잘못된 표, 빈 명단, 중복 선수, 확률 합계 오류는 저장 전에 거부한다.

`python -m unittest discover -s scripts -p test_import_hof_recruit.py`로 수집기 검증, `npm test`로 확률 경계·목표 중단·기록 검증을 실행한다.
